PROJECT 01 MECHATRONIC SYSTEMS

Mini mechatronic
foosball table

A compact tabletop game bringing motion control, a physical interface and a custom mechanical assembly into one working prototype.

ArduinoCAD & 3D printingMotion control
Designed & built
I developed the mechatronic prototype as part of a course project, integrating stepper-driven movement, a 5 V solenoid striker and goal sensing into a team-designed, 3D-printed structure.
Tested & refined
I evaluated movement and system response, adjusted the control code and worked through hardware integration issues.
Project context & next steps +

Course: Implementation of Mechatronic Systems. The design adapts an existing automated foosball concept using accessible components, an Arduino Uno, a NEMA stepper motor and a custom 12 V / 5 V supply.

Next documentation step: add measured response times and clarify the individual ownership of each mechanical component. Computer vision is a potential extension, not an implemented feature.

PROJECT 02 MEASUREMENT & VALIDATION

AC frequency
measurement system

A measurement prototype connecting signal acquisition, frequency analysis and a structurally evaluated enclosure.

Python / FFTArduino / UARTSolidWorks
Designed & built
I developed an Arduino–Python measurement workflow using an ACS712 sensor and serial communication, with FFT processing and graphical signal analysis.
Simulated & tested
I designed an MDF enclosure in SolidWorks and evaluated a 1,000 N load case. The project included enclosure assembly, load testing and adjustment of the measurement system.
Project context & next steps +

Course: Mechatronic Integration. The work combines electronics, software and mechanical design in a single measurement instrument.

The 1,000 N figure is a project load case, not a certified load rating. Accuracy, sampling parameters and test records are still to be added to this portfolio.
