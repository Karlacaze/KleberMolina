PROJECT 01 7TH SEMESTER · PCB DESIGN · AUTOMOTIVE TESTING

ECU power management
& testing system

A system for International Motors Mexico that controls power to four ECUs, monitors their CAN messages and electrical behaviour, and runs automated tests.

I was responsible for the circuit design, PCB layout, component calculations, assembly and soldering: one replaceable board per ECU, with MOSFET switching for fast, repeated operation without contact wear. The project was selected for ExpoIngenierías and demonstrated live with International ECUs.

KiCadESP32 / MicroPythonCANVISAOscilloscope
Read more +

Validation included extended operation, repeated switching, CAN reception from real ECUs and sensor readings checked against lab instruments. I used an oscilloscope to measure switching response times. Safety features included a main fuse, shutdown on over-voltage and a fail-safe if the computer disconnected.

Hardware and documentation were handed over to International. Due to their confidentiality policy, ECU-specific CAN messages, VISA command sequences and detailed test results cannot be shown. ExpoIngenierías certificate ↗

PROJECT 02 6TH SEMESTER · INDUSTRIAL ROBOTICS · PLC · HMI

Robotic assembly station
— MIT FrED Factory

I led a four-person team rebuilding Station 3 of the MIT FrED Factory line, where a KUKA robot handles and presses together the funnel assembly of a filament extrusion device.

With the previous PLC programs unavailable, I corrected the KUKA interface wiring, replaced the Siemens + Allen-Bradley arrangement with one Siemens PLC in ladder logic, rewrote the robot sequence from scratch and developed the HMI.

Siemens PLCTIA PortalKUKAHMI
Read more +

Without the usual robot programming software, I wrote the operating logic directly as code from recorded positions. The HMI shows process progress, timers, robot status, sensor states and missing-part warnings, with door interlocks and robot-status checks. The handover included schematics, TIA Portal files and operating documentation.

In the same course, a small project with Schneider Electric Mexico won a participant-voted award. LinkedIn post ↗

PROJECT 06 MEASUREMENT · SIGNAL ANALYSIS

AC frequency
measurement system

A power-supply monitor that tracks frequency changes around 60 Hz as loads are added or removed.

An Arduino with an ACS712 sensor sent batches of readings to Python, where I used NumPy’s FFT to estimate frequency with a live Matplotlib view. I designed the MDF case in SolidWorks to support 100 kg; in an informal test it held about 220 kg.
